# GRAD Loadout

Declarative loadout system for Arma3 by [Gruppe Adler](https://www.gruppe-adler.de/) - edited by Andx.

!!! note "Origin"
    GRAD Loadout is a continuation of mostly [Cephei](https://github.com/Cephel)'s work on [A3G Loadout](https://github.com/v-Arma/a3g-loadout). That project had gone stale, and enough had changed here that it was renamed to its own repo/project. — Fusselwurm, 2016-08-16
